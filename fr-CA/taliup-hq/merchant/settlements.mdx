**Règlements** affiche les lots de cartes de vos terminaux de paiement : ce qui est encore ouvert et ce qui est déjà réglé. C'est un rapport seulement. Vous fermez un lot sur le terminal; consultez [Fermer le lot](/fr-CA/taliup-pos/transactions/close-batch).

## Avant de commencer

- **Règlements** apparaît dans Taliup HQ pour les entreprises dont les terminaux de paiement sont des terminaux PAX traités par Nuvei.
- Les lots ouverts exigent un terminal de paiement actif. Sinon, la page affiche **Aucun terminal actif**.

## Accès

Dans Taliup HQ, ouvrez le groupe **Paiements reçus** de la barre latérale et sélectionnez **Règlements**. Utilisez **Choisir un terminal** en haut pour changer de terminal.

## Lot ouvert

L'onglet **Lot ouvert** affiche le numéro du **Lot ouvert** du terminal et **Pas encore réglé**, avec :

- **Ventes nettes** (ventes − remboursements + pourboires), le nombre de ventes, les pourboires et le nombre de remboursements.
- **Transactions de ce lot**, chacune avec son statut (par exemple **Capturé**, **Autorisé** ou **Remboursé**), son heure et son montant.

Il affiche aussi le **Dernier lot réglé** : sa date de règlement, le **Montant réglé** et ses totaux par type de carte, comptant et retours. Sélectionnez **Voir tous les lots réglés** pour ouvrir l'autre onglet.

Si le terminal n'a rien de non réglé, l'onglet affiche **Aucun lot ouvert**.

## Lots réglés

L'onglet **Lots réglés** liste les lots réglés avec leur numéro, leur terminal, leur date de règlement, leur nombre de transactions et leur montant réglé. Un lot réglé pour tout un emplacement affiche **Tous les terminaux de l'emplacement**.

Affinez la liste avec **Rechercher par numéro de lot**, le terminal et le **Mois**. Les totaux en haut couvrent tout ce qui correspond aux filtres.

## Si quelque chose n'apparaît pas

- **Impossible de charger vos règlements** : actualisez la page.
- Un paiement manque dans le lot ouvert : ouvrez-le dans [Transactions](/fr-CA/taliup-hq/merchant/transactions) ou sur le terminal.
- Pour toute question sur le règlement des lots, communiquez avec le [soutien](/fr-CA/taliup-pos/help/support).
