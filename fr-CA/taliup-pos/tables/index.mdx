**Tables** apparaît sur Accueil lorsque la gestion des tables est activée pour le marchand. Utilisez-la pour voir la salle, démarrer des commandes et continuer le service dans Caisse.

Si la gestion des tables n'est pas activée, l'écran indique que la gestion des tables n'est pas activée pour cette entité.

<Frame caption="grille de salle Tables avec cartes Available / Occupied.">
  ![grille de salle Tables avec cartes Available / Occupied](/images/taliup-pos/tables/floor.png)
</Frame>

## Comment y arriver

Depuis Accueil, appuyez sur **Tables**.

## Aperçu de la salle

Chaque carte affiche le nom de la table, le statut et la capacité ou la taille du groupe.

| Statut | Ce que vous faites habituellement |
|---|---|
| **Available** | Appuyez sur **Start Order**, ou ouvrez les actions pour réserver / renommer |
| **Reserved** | Appuyez sur **Check In**, ou annulez la réservation |
| **Occupied** | Ouvrez la commande liée dans Caisse, ou consultez les commandes / en démarrez une autre |

Tirez vers le bas pour actualiser. État vide : **No tables found.**

## Démarrer une commande de table

<Steps>
  <Step title="Choisir une table disponible ou réservée">
    Appuyez sur **Start Order** (Available) ou **Check In** (Reserved). Vous pouvez aussi utiliser **New Order** depuis le dialogue d'actions de la table.
  </Step>
  <Step title="Saisir la taille du groupe">
    Dans **Enter Party Size**, saisissez le nombre d'invités et confirmez.
  </Step>
  <Step title="Continuer dans Caisse">
    Taliup POS ouvre [Caisse](/fr-CA/taliup-pos/register) pour cette table afin d'ajouter des articles et d'encaisser.
  </Step>
</Steps>

## Actions de table

Appuyez longuement sur une table (ou utilisez les actions de la carte) pour ouvrir les options selon le statut :

| Statut | Actions |
|---|---|
| **Available** | **Reserve Table**, **New Order**, **Change Table Name** |
| **Reserved** | **Check In**, **Cancel Reservation**, **Change Table Name** |
| **Occupied** | **View Orders**, **New Order** — le renommage est bloqué tant que la table est occupée |

Les cartes Occupied avec une commande liée ouvrent cette commande dans Caisse. Elles peuvent aussi afficher le solde restant et les détails serveur / heure d'assise dans les dialogues.

## Commandes sur une table

Depuis une table occupée, vous pouvez ouvrir l'écran des commandes de cette table (**Orders** avec le nom de la table). Le menu overflow peut inclure :

- **New Order**
- **Group by Guest**
- **Split Order**
- **Merge Orders**
- **Open In Register**
- **Move Order**
- **Cancel Order**

Les raccourcis par commande peuvent inclure **Add**, **More** et **Cancel**. Depuis **More**, vous pouvez **Add Item**, partager/fusionner/déplacer ou annuler.

### Déplacer, partager, fusionner

| Action | Ce qui se passe |
|---|---|
| **Move Order** / **Change Table** | Choisir une autre table (places, statut, serveur) |
| **Split Order** | Partager les articles ou les invités en plusieurs factures |
| **Merge Orders** | Combiner les commandes et éventuellement **Set as primary** |
| **Group by Guest** | Organiser les articles par invité |

Annuler une commande ouverte demande de confirmer : **Please confirm you want to cancel this open order?**

Plusieurs de ces outils apparaissent aussi dans Caisse sous [Options](/fr-CA/taliup-pos/register/options) lorsqu'une commande de table est ouverte.

## Plans de salle

Regroupez les tables par pièce avec des plans de salle, par exemple **Terrasse**, **Bar** ou **Salle privée**. Chaque plan de salle est un onglet. Balayez ou touchez les onglets pour changer de pièce.

Passez d'une vue à l'autre en haut de **Tables** :

| Vue | Utilisez-la pour |
|---|---|
| **Plan de salle** | Voir les tables là où elles sont dans la pièce |
| **Liste** | Voir les tables en liste, dans l'ordre de votre choix |

Les tables qui ne sont dans aucun plan apparaissent sous **Non groupées**.

En mode paysage, une commande de table dans Caisse a une fiche **Actions de table** avec les outils de la table. Une fois la commande de table terminée, Taliup POS revient à l'écran Tables d'où vous veniez.

### Gérer les plans de salle

Appuyez sur **Gérer les plans de salle** pour ajouter, renommer, réordonner, désactiver ou supprimer des plans. Appuyez sur un plan pour ouvrir **Paramètres du plan de salle** :

| Paramètre | Ce qu'il fait |
|---|---|
| **Tables de ce plan** | Cochez des tables pour les déplacer dans ce plan. Glissez-les pour changer leur ordre dans la vue liste |
| **Désactiver le plan** | Bloque les nouvelles commandes et réservations sur ses tables. Les commandes existantes peuvent être terminées. Toutes ses tables doivent d'abord être libres |
| **Supprimer le plan** | Ses tables passent sous **Non groupées**. Elles ne sont pas supprimées |

### Modifier la disposition

<Steps>
  <Step title="Commencer la modification">
    Sur un plan de salle, appuyez sur **Modifier la disposition**. Une grille d'alignement apparaît sur le canevas.
  </Step>
  <Step title="Disposer les tables">
    Glissez une table pour la déplacer. Pincez pour la redimensionner, ou tournez deux doigts pour la faire pivoter. La rotation s'aligne par pas de 45°. Utilisez **Propriétés de la table** pour une rotation précise par pas de 15°.
  </Step>
  <Step title="Ajouter des tables">
    Utilisez **Ajouter une table** pour une nouvelle table, ou **Ajouter une table existante** pour en amener une d'un autre plan.
  </Step>
  <Step title="Enregistrer">
    Appuyez sur **Enregistrer le plan**. Appuyez sur **Abandonner** pour annuler les changements.
  </Step>
</Steps>

Les tables ne peuvent pas se chevaucher. Si c'est le cas, Taliup POS les met en évidence pour que vous les sépariez avant d'enregistrer de nouveau.

### Ajouter ou modifier une table

Le formulaire de table contient **Nom**, **Places**, **Forme et taille** (avec un aperçu) et **Plan de salle**. Sans plan de salle, la table va sous **Non groupées**.

Seules les tables libres peuvent être supprimées ou déplacées vers un autre plan. Une table avec une commande ouverte ou une réservation doit d'abord être libérée. Les ventes passées ne sont pas touchées.

Vous pouvez aussi gérer les plans de salle dans Taliup HQ sous **Gestion de table**.
