La plupart des questions sur Taliup POS et Taliup HQ trouvent réponse dans cette documentation. Quand vous avez besoin d'une personne, joignez le soutien.

## Chercher dans la documentation

Allez sur [docs.taliuphq.com](https://docs.taliuphq.com/) et utilisez la barre de recherche, ou commencez par [Taliup POS](/fr-CA/taliup-pos) ou [Dépannage](/fr-CA/taliup-pos/help/troubleshooting).

Si l'[assistant IA](/fr-CA/taliup-pos/help/assistant) est activé pour votre entreprise, vous pouvez aussi lui poser la question dans Taliup POS.

## Coordonnées du soutien

[tech@taliup.ca](mailto:tech@taliup.ca) · +1 800-468-4798

## Si vous travaillez avec un ISO ou un partenaire

Beaucoup d'entreprises obtiennent Taliup par l'entremise d'un ISO ou d'un partenaire. Votre ISO ou partenaire peut offrir son propre canal de soutien. Dans ce cas, utilisez ce canal plutôt que le soutien Taliup.

## Ce qu'il faut avoir sous la main

Le soutien peut vous aider plus vite si vous avez :

- Le nom de votre entreprise.
- L'**ID de l'appareil** qui a le problème. Il figure dans Taliup HQ sous **Paramètres** → **Appareils**.
- La version de Taliup POS, affichée au bas de **Paramètres** sur l'appareil.
- Ce que vous faisiez, le message exact à l'écran et l'heure.

<Warning>
  N'envoyez jamais au soutien de numéro de carte complet, de code de sécurité de carte, de mot de passe ni de NIP.
</Warning>
