**Entreprise** affiche les informations du profil marchand et les grandes fonctions activées. La plupart des valeurs ici sont gérées dans Taliup HQ et apparaissent en lecture seule sur l'appareil.

<Note>
  **Capture d'écran à venir :** champs de profil et bascules de fonctions des paramètres Entreprise.  
  Chemin prévu : `/images/taliup-pos/settings/business.png`
</Note>

## Comment y arriver

Accueil → **Paramètres** → **Entreprise**.

## Champs du profil

| Champ | Notes |
|---|---|
| **Name** | Nom du marchand / de l'entité |
| **Description** | Description provenant de HQ |
| **Industry Type** | Détermine les libellés Menu vs Catalogue dans l'application |

## Indicateurs de fonctions

Ces bascules reflètent la configuration HQ (affichage seulement sur l'appareil) :

| Contrôle | Zone liée |
|---|---|
| **Quickbooks** | La liste Commandes peut afficher **Sync Sales** lorsque c'est activé |
| **Feuilles de temps** | Pointer / quitter sur Accueil |
| **Calendrier** | Tuile Calendrier sur Accueil |
| **Inventaire** | [Inventaire](/fr-CA/taliup-pos/catalog/inventory) sous Menu/Catalogue |

Modifiez ces fonctions dans Taliup HQ (plans/fonctionnalités et paramètres d'entité), pas sur l'appareil.
