Une carte-cadeau est un mode de paiement, comme le comptant ou une carte bancaire. Vous la choisissez au moment d'encaisser une commande.

## Avant de commencer

- Les cartes-cadeaux doivent être actives pour votre emplacement.
- Vous avez besoin de la carte, ou du code d'une carte reçue par courriel.

## Prendre un paiement par carte-cadeau

<Steps>
  <Step title="Aller au paiement">
    Saisissez la commande normalement et passez à l'écran de paiement.
  </Step>
  <Step title="Choisir carte-cadeau">
    Sélectionnez l'option de paiement par carte-cadeau.
  </Step>
  <Step title="Saisir la carte">
    Glissez, scannez ou saisissez le numéro. Si le client a une carte reçue par courriel, scannez son code ou tapez le code court.
  </Step>
  <Step title="Confirmer le montant">
    Confirmez le montant à prélever sur la carte.
  </Step>
  <Step title="Terminer la vente">
    Le PDV applique le paiement et imprime le reçu. S'il reste un montant dû, poursuivez avec un autre mode de paiement.
  </Step>
</Steps>

## Quand la carte ne couvre pas la commande

Si le solde est inférieur au montant dû, le PDV prélève ce qui est sur la carte et laisse le reste à payer. La commande reste ouverte jusqu'au paiement du solde.

<Steps>
  <Step title="Appliquer la carte">
    Prenez le paiement par carte-cadeau. Le PDV applique le solde disponible.
  </Step>
  <Step title="Vérifier ce qui reste">
    L'écran de paiement affiche le montant restant dû.
  </Step>
  <Step title="Prendre le reste">
    Encaissez le reste comptant, par carte bancaire ou avec une autre carte-cadeau.
  </Step>
</Steps>

<Tip>
  Si un client ne sait pas combien il reste sur sa carte, [vérifiez le solde](/fr-CA/taliup-pos/gift-cards/balance) avant de commencer la vente.
</Tip>

## Dépannage

| Situation | Quoi vérifier |
| --- | --- |
| Carte refusée | La carte est peut-être vide ou inactive. Vérifiez le solde |
| Moins prélevé que prévu | La carte n'avait pas assez. Encaissez le reste autrement |
| Code courriel non reconnu | Retapez le code court avec soin, ou scannez de nouveau |
| Réseau coupé pendant le paiement | Réessayez. La carte ne sera pas débitée deux fois |
| Le client change d'avis après avoir payé | [Annulez le paiement par carte-cadeau](/fr-CA/taliup-pos/gift-cards/void-refund) |
