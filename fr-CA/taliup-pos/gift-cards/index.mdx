Taliup POS peut vendre des cartes-cadeaux, les accepter en paiement, vérifier ce qu'il reste sur une carte, et annuler un paiement par carte-cadeau quand une commande change.

<Note>
  Les cartes-cadeaux exigent une version de Taliup POS qui les prend en charge. Si vous ne voyez pas les options de cartes-cadeaux sur votre appareil, il est sur une version antérieure.
</Note>

---

## Avant de commencer

- Les cartes-cadeaux doivent être **actives pour votre emplacement**. Un gestionnaire les active dans Taliup HQ. Voir [Cartes-cadeaux dans le portail marchand](/fr-CA/taliup-hq/features/gift-cards).
- Votre appareil doit être enregistré pour les cartes-cadeaux. Les terminaux ajoutés après l'activation le sont automatiquement.
- Vous avez besoin de la carte physique pour la plupart des actions.

Si les options manquent, l'emplacement n'est pas encore actif ou votre appareil n'est pas enregistré. Un gestionnaire peut vérifier les deux dans Taliup HQ.

## Comment se comportent les cartes-cadeaux

Quelques points utiles à connaître avant de les utiliser au comptoir.

**Vendre et encaisser sont deux choses différentes.** Vendre une carte est une vente ordinaire que le client paie comptant ou par carte. L'encaisser, c'est utiliser la carte-cadeau comme mode de paiement sur la commande de quelqu'un d'autre.

**Une carte n'est chargée qu'après le paiement du client.** Quand vous vendez une carte-cadeau, la valeur y est placée une fois le paiement approuvé, jamais avant.

**Une carte-cadeau peut couvrir une partie d'une commande.** Si le solde est inférieur au montant dû, le PDV applique ce qui est disponible et laisse le reste à un autre mode de paiement.

**Les soldes sont détenus par le fournisseur.** Le solde affiché est lu en direct lors de l'utilisation ou de la vérification : il est donc exact même si la carte a servi à un autre de vos emplacements.

**Réessayer est sécuritaire.** Si le réseau tombe et que vous ne savez pas si l'opération a passé, réessayer ne charge ni ne débite une carte deux fois.
