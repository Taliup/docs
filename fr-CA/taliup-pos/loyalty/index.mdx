La fidélité récompense vos clients réguliers avec des points. Ils gagnent des points sur leurs achats et les dépensent en rabais sur une commande ultérieure. Aucune carte n'est nécessaire : vous trouvez un membre par numéro de téléphone, courriel ou nom.

## Avant de commencer

- La fidélité doit être **active pour votre emplacement**. Un gestionnaire l'active dans Taliup HQ. Voir [Fidélité dans le portail marchand](/fr-CA/taliup-hq/features/loyalty).
- Votre appareil doit être enregistré pour la fidélité. Les terminaux ajoutés après l'activation le sont automatiquement.
- Le client doit être un **client** dans Taliup. Vous pouvez l'ajouter sur-le-champ au moment de l'inscrire.

Si les options de fidélité manquent, l'emplacement n'est pas encore actif ou votre appareil n'est pas enregistré. Un gestionnaire peut vérifier les deux dans Taliup HQ.

## Comment fonctionnent les points

**Les points se gagnent sur les articles, pas sur les taxes.** Votre gestionnaire définit combien de points chaque dollar rapporte. Les points sont calculés sur le sous-total de la commande après rabais et avant taxes; les pourboires et les taxes ne rapportent donc jamais de points.

**Les récompenses viennent par tranches.** Par exemple, chaque tranche de 100 points peut valoir 5,00 $. Un membre ayant 250 points peut échanger 100 ou 200 points, pas 250.

**Une récompense est un rabais, pas un paiement.** Échanger des points réduit le sous-total de la commande avant taxes. Le client paie le reste en argent, par carte bancaire ou par carte-cadeau.

**Les points fonctionnent dans tous les emplacements de cette entreprise.** Un membre qui gagne des points dans un magasin peut les échanger dans un autre. Les points ne fonctionnent jamais dans une autre entreprise.

**Les soldes sont détenus par le fournisseur.** Le solde affiché est lu en direct lors de la consultation : il est donc exact même si le membre vient d'être servi à un autre emplacement.
