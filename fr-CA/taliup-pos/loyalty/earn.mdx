Les points sont attribués automatiquement quand une commande associée à un membre est payée. Votre seule tâche est d'associer le membre avant l'encaissement.

## Avant de commencer

- La fidélité doit être active pour votre emplacement.
- Le client doit être inscrit. Sinon, [inscrivez-le](/fr-CA/taliup-pos/loyalty/enroll) d'abord.

## Associer un membre à une commande

<Steps>
  <Step title="Saisissez la commande">
    Ajoutez les articles comme d'habitude.
  </Step>
  <Step title="Ouvrez Fidélité">
    Choisissez **Fidélité** sur la commande et cherchez le membre par téléphone, courriel ou nom.
  </Step>
  <Step title="Touchez le membre">
    Son solde s'affiche et le membre est associé à la commande.
  </Step>
  <Step title="Encaissez">
    Terminez la vente avec n'importe quel mode de paiement. Quand le paiement est approuvé, le PDV attribue les points et imprime le nouveau solde sur le reçu.
  </Step>
</Steps>

## Combien de points

Le gestionnaire fixe le taux dans Taliup HQ. Les points sont calculés sur le **sous-total après rabais et avant taxes**, puis arrondis selon le programme. Les pourboires, les frais et les taxes ne rapportent jamais de points. Une vente sous l'achat minimum du programme ne rapporte rien.

Si une récompense a été échangée sur la même commande, les points sont gagnés sur le sous-total **après** le rabais de la récompense.

## Quand la commande est annulée

Annuler une commande qui a rapporté des points les reprend automatiquement. Si le membre en a déjà dépensé une partie, l'annulation est refusée par le fournisseur, car un solde ne peut pas être négatif. Avisez un gestionnaire pour qu'il ajuste le membre.

## Dépannage

| Situation | Quoi vérifier |
| --- | --- |
| Aucun point sur le reçu | Le membre n'a pas été associé avant l'encaissement, ou la vente était sous l'achat minimum |
| Moins de points que prévu | Les points se basent sur le sous-total avant taxes après rabais, arrondis selon le programme |
| « Phone already taken » indiqué sur le membre | Le fournisseur n'a pas pu associer le téléphone du client au compte. Les points sont quand même attribués. Demandez à un gestionnaire de vérifier le téléphone sur la fiche client |
| Réseau coupé après le paiement | Réessayez depuis la commande. Les points ne sont jamais attribués deux fois pour la même vente |
