**Business** shows merchant profile information and which major features are enabled. Most values here are managed in Taliup HQ and appear read-only on the terminal.

## How to get here

Home → **Settings** → **Business**.

## Profile fields

| Field | Notes |
|---|---|
| **Name** | Merchant / entity name |
| **Description** | Description from HQ |
| **Industry Type** | Drives Menu vs Catalog labels across the app |

## Feature indicators

These toggles reflect HQ configuration (display only on the device):

| Control | Related area |
|---|---|
| **Quickbooks** | Orders list may show **Sync Sales** when enabled |
| **Time Sheets** | Clock in / clock out on Home |
| **Scheduling** | Scheduling tile on Home |
| **Inventory** | [Inventory](/taliup-pos/catalog/inventory) under Menu/Catalog |

Change these features in Taliup HQ (plans/features and entity settings), not on the terminal.
