Use **Discounts** to define discounts staff can apply during a sale. Access requires the catalog discounts feature.

<Frame caption="Discounts list with Disc. Code, Value, Applied To.">
  ![Discounts list with Disc. Code, Value, Applied To](/images/taliup-pos/catalog/discounts.png)
</Frame>

## How to get here

Home → **Menu** / **Catalog** → **Discounts**.

## Create a discount

<Steps>
  <Step title="Tap Add New">
    Open the discount form.
  </Step>
  <Step title="Enter code and value">
    Set **Disc. Code**, choose **Percentage** or **Fixed Amount**, and enter the value.
  </Step>
  <Step title="Configure how it applies">
    Set **Applied Before Tax?** (YES/NO), then **Order Level** or **Item Level**.
  </Step>
  <Step title="Choose catalog and category">
    Select **Applied Catalog** / **Applied Menu**. For item-level discounts, also select **Applied Category** (required).
  </Step>
  <Step title="Confirm">
    Save the discount.
  </Step>
</Steps>

List columns: **Disc. Code**, **Value**, **Applied To**.

Open a discount to edit or **Delete**. Apply discounts on an order from Register [Options](/taliup-pos/register/options) → **Add Order Discounts**.
