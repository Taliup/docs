**Inventory** tracks stock for sellable products and, when enabled, raw materials and units. Access requires the inventory feature.

<Frame caption="Inventory products list with Name, SKU, QTY.">
  ![Inventory products list with Name, SKU, QTY](/images/taliup-pos/catalog/inventory.png)
</Frame>

## How to get here

Home → **Menu** / **Catalog** → **Inventory**.

## Navigation

| Section | Availability |
|---|---|
| **Products** | Always (within Inventory) |
| **Raw Materials** | Typically restaurants; may require an inventory add-on |
| **Units** | When units feature is enabled |

## Products

List columns: **Name**, **SKU**, **QTY.** Search by name, SKU, or price.

Open a product to edit inventory. The header shows name, **SKU**, **Price**, and **Total Stock** (with the unit abbreviation when one is set).

- Quantity on hand
- **RP.** (reorder point) when enabled
- **Sold by** — unit and **Weighable** (see below)

Tap **Save** to write stock and Sold by together, or **Cancel**. Options may include syncing inventory with products.

### Sold by

The **Sold by** card is on the product inventory screen.

<Frame caption="Roast Beef inventory with Weighable on and unit kilograms (kg).">
  ![Inventory for Roast Beef SKU 88101 with Weighable turned on, unit kilograms (kg), and quantity 12.05](/images/taliup-pos/register/inventory-sold-by-weighable.png)
</Frame>

Help text: *Unit for this product. Turn on Weighable for scale labels; stock deducts by the scanned weight.*

| Control | What it does |
|---|---|
| **Weighable** | Sold by weight from a scale barcode or [Enter weight](/taliup-pos/settings/general). Price is catalog `$/unit ×` weight. |
| **Unit** | Measurement unit. Required when Weighable is on. |
| **Quantity Deducted per Sale** | How much stock to remove for one packaged sale. Hidden when Weighable is on. |

**When Weighable is off**

- **Unit** can be **Per Item (default)** or any unit in the list.
- If the units feature is on, the list includes **+ Add Custom Unit**.
- Set **Quantity Deducted per Sale** (for example `250` if each sale uses 250 g).

**When Weighable is on**

- **Unit** lists only **kg**, **g**, **lb**, and **oz**. Pick one before you save.
- **Quantity Deducted per Sale** is hidden. Help text: *The scanned weight is deducted from inventory at checkout.*
- **+ Add Custom Unit** is not in this list. Create a weight unit under **Units** (or in Taliup HQ) first.
- If no weight unit exists, Taliup shows: *Add a kg, g, lb, or oz unit in HQ Inventory > Units before marking this product weighable.*

Weighable needs a catalog price per unit. **Custom price** and **Weighable** cannot be on together — turn Custom price off in Taliup HQ first. See [Scale barcodes](/taliup-pos/register/scale-barcodes) and [Scale items](/taliup-hq/features/scale-items).

## Raw materials

Title **Raw Materials**. Tap **Add Raw Material** or edit a row.

| Field | Notes |
|---|---|
| **Name** | Material name |
| **Unit** | Unit of measure |
| **Qty on Hand** | Adjustable quantity |
| **Inventory Threshold** | Low-stock threshold |

Search by name. Delete is available when editing.

## Units

Title **Units**. Search by name or abbreviation. Tap **Add Custom Unit** or open a row to edit.

<Frame caption="Inventory Units list with Name, Abbreviation, and Precision.">
  ![Units list showing Gram, kilograms, millilitres, Ounce, and Pound with Add Custom Unit](/images/taliup-pos/register/units.png)
</Frame>

| Field | Notes |
|---|---|
| **Name** | Unit name |
| **Abbreviation** | Short code shown on Register and receipts. Use **kg**, **g**, **lb**, or **oz** if this unit will back a weighable product. |
| **Precision** | How many decimal places to display |

Taliup HQ creates **Kilogram (`kg`)**, **Gram (`g`)**, **Pound (`lb`)**, and **Ounce (`oz`)** for new merchants. You can add more units here for packaged items.

A weighable product only accepts those four abbreviations. Other units stay in the picker when **Weighable** is off. After you add `kg` / `g` / `lb` / `oz`, they appear in the weight-only **Unit** list on **Sold by**.

<Warning>
  Deleting a unit that a weighable product uses turns **Weighable** off on that product. Reassign a weight unit and turn **Weighable** back on.
</Warning>
