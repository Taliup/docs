Labeled **Products** or **Items** depending on industry type. This is the main list of sellable goods.

<Frame caption="Products/Items list with Add New.">
  ![Products/Items list with Add New](/images/taliup-pos/catalog/products.png)
</Frame>

## How to get here

Home → **Menu** / **Catalog** → **Products** or **Items**.

## Add a product or item

<Steps>
  <Step title="Tap Add New">
    Open the create form.
  </Step>
  <Step title="Enter details">
    Fill in **Name** (required), **Description**, **Custom Price** (YES/NO), **Price** (required when not custom), and **Sku** when applicable.
  </Step>
  <Step title="Confirm">
    Save the new product/item.
  </Step>
</Steps>

## Edit a product or item

Open a row to edit. The editor includes:

| Tab | Contents |
|---|---|
| **General** | Name, Description, Custom Price, Price, Sku, Save |
| **Attributes** / **Modifiers** | Attach option groups (**Add New** / **Add From Existing**) |
| **Taxes** | Attach taxes (**Add New** / **Add From Existing**) |

Use **Delete** to remove the product/item after confirmation.

Search supports name lookup (and barcode input where configured).
