**Tables** appears on Home when table management is enabled for the merchant. Use it to see the floor, start orders, and continue seating work in Register.

If table management is not enabled, the screen shows that table management is not enabled for this entity.

<Frame caption="Tables floor grid with Available / Occupied cards.">
  ![Tables floor grid with Available / Occupied cards](/images/taliup-pos/tables/floor.png)
</Frame>

## How to get here

From Home, tap **Tables**.

## Floor overview

Each table card shows the table name, status, and capacity or party size.

| Status | What you typically do |
|---|---|
| **Available** | Tap **Start Order**, or open actions to reserve / rename |
| **Reserved** | Tap **Check In**, or cancel the reservation |
| **Occupied** | Open the linked order in Register, or view orders / start another |

Pull down to refresh the floor. Empty state: **No tables found.**

## Start a table order

<Steps>
  <Step title="Select an available or reserved table">
    Tap **Start Order** (Available) or **Check In** (Reserved). You can also use **New Order** from the table actions dialog.
  </Step>
  <Step title="Enter party size">
    In **Enter Party Size**, enter the number of guests and confirm.
  </Step>
  <Step title="Continue in Register">
    Taliup POS opens [Register](/taliup-pos/register) for that table so you can add items and take payment.
  </Step>
</Steps>

## Table actions

Long-press a table (or use the card actions) to open status-specific options:

| Status | Actions |
|---|---|
| **Available** | **Reserve Table**, **New Order**, **Change Table Name** |
| **Reserved** | **Check In**, **Cancel Reservation**, **Change Table Name** |
| **Occupied** | **View Orders**, **New Order** — renaming is blocked while occupied |

Occupied cards with a linked order open that order in Register when tapped. Occupied cards may also show remaining balance and server / seated-at details in dialogs.

## Orders on a table

From an occupied table you can open that table’s orders screen (**Orders** with the table name). Overflow options can include:

- **New Order**
- **Group by Guest**
- **Split Order**
- **Merge Orders**
- **Open In Register**
- **Move Order**
- **Cancel Order**

Per-order shortcuts can include **Add**, **More**, and **Cancel**. From **More** you can **Add Item**, split/merge/move, or cancel.

### Move, split, merge

| Action | What happens |
|---|---|
| **Move Order** / **Change Table** | Pick another table (shows seats, status, server) |
| **Split Order** | Split items or guests into additional checks |
| **Merge Orders** | Combine orders and optionally **Set as primary** |
| **Group by Guest** | Organize items by guest |

Canceling an open order asks you to confirm: **Please confirm you want to cancel this open order?**

Many of the same table tools also appear in Register under [Options](/taliup-pos/register/options) while a table order is open.

## Floor plans

Group tables by room with floor plans, for example **Patio**, **Bar**, or **Private room**. Each floor plan is a tab. Swipe or tap the tabs to switch rooms.

Switch between two views at the top of **Tables**:

| View | Use it to |
|---|---|
| **Floor plan** | See tables where they sit in the room |
| **List** | See tables as a list, in an order you choose |

Tables that are not in a floor plan appear under **Ungrouped**.

In landscape, a table order in Register has a **Table actions** sheet with the table's tools. After you finish a table order, Taliup POS returns to the Tables screen you came from.

### Manage floor plans

Tap **Manage floor plans** to add, rename, reorder, disable, or delete plans. Tap a plan to open **Floor plan settings**:

| Setting | What it does |
|---|---|
| **Tables in this plan** | Tick tables to move them into this plan. Drag them to change their order in the list view |
| **Disable plan** | Stops new orders and reservations on its tables. Existing orders can still be completed. All its tables must be free first |
| **Delete plan** | Its tables move to **Ungrouped**. They are not deleted |

### Edit the layout

<Steps>
  <Step title="Start editing">
    On a floor plan, tap **Edit layout**. An alignment grid appears on the canvas.
  </Step>
  <Step title="Arrange tables">
    Drag a table to move it. Pinch to resize it, or twist to rotate it. Rotation snaps to 45°. Use **Table properties** for exact rotation in 15° steps.
  </Step>
  <Step title="Add tables">
    Use **Add table** for a new table, or **Add existing table** to bring one in from another plan.
  </Step>
  <Step title="Save">
    Tap **Save layout**. Tap **Discard** to throw the changes away.
  </Step>
</Steps>

Tables cannot overlap. If they do, Taliup POS highlights them so you can move them apart and save again.

### Add or edit a table

The table form has **Name**, **Seats**, **Shape & size** (with a preview), and **Floor plan**. Without a floor plan, the table goes to **Ungrouped**.

Only free tables can be deleted or moved to another plan. A table with an open order or a reservation must be cleared first. Past sales are not affected.

You can also manage floor plans in Taliup HQ under **Table Management**.
