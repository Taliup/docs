The Factor4 Accounts Hub is the single place to see every gift card account Taliup has provisioned. Use it to confirm a merchant is set up correctly, to see why an activation looks wrong, and to check what Factor4 currently holds.

Open **Factor4 Hub** in the admin sidebar.

<Note>
  The hub is read-only. It reads from Factor4 and from Taliup, and changes nothing in either. Merchants activate and cancel gift cards themselves.
</Note>

---

## Access

The hub requires the **Factor4Hub** permission, which is granted to super administrators. What you can see is scoped to your organization, so an ISO admin sees only their own merchants.

---

## Reading the list

Each row is one Factor4 location, matched back to the Taliup entity and location it belongs to.

| Column | What it tells you |
| --- | --- |
| **Merchant and location** | The Taliup entity and location, when the Factor4 record can be matched |
| **Factor4 location** | The location id held by Factor4 |
| **Status** | The status Factor4 reports, such as Enabled or Suspended |
| **Health** | Whether the account looks complete: credentials stored, terminals mapped, program linked |
| **Billing** | The subscription state behind the activation |

Records are matched by the cross-reference id Taliup sets when it creates the location. A Factor4 location created outside Taliup will appear unmatched.

### Billing states

| State | Meaning |
| --- | --- |
| **Active** | A paid subscription is running |
| **Cancellation scheduled** | Cancelled, still working until the paid period ends |
| **Pending** | A checkout was started but not completed |
| **Suspended** | Payment failed or the period ended |
| **Cancelled** | Ended |
| **None** | No subscription found for this location |

## Environment switch

The hub shows one environment at a time. Switch between **test** and **live** at the top of the page.

A location set up in both environments appears once per environment, with different Factor4 ids and different cards. If a merchant reports missing cards, check that you are looking at the right environment before anything else.

Environments blocked by the platform policy are not selectable. See [Overview](/taliup-hq/admin/gift-cards/overview#test-and-live-environments).

---

## Account details

Click a row to open the detail panel. It queries Factor4 live and shows:

- **Location** as Factor4 holds it, including address and status
- **Terminals** registered against the location, with their POS ids
- **Programs** linked to the location, and the permissions the link grants
- **Billing** detail for the subscription behind the activation
- **Stored configuration**, including the credentials Taliup holds for the location

<Warning>
  The detail panel can reveal the stored location credentials. Treat them as production secrets and do not copy them out of the hub.
</Warning>

---

## Sync

The list is cached for a few minutes so the page stays fast. **Sync** forces a fresh read from Factor4.

Use it after a merchant activates, or when you are checking a change someone just made on the Factor4 side. Each sync makes several calls to Factor4, so avoid running it repeatedly.

---

## What the hub is good for

| Question | Where to look |
| --- | --- |
| Did this merchant's activation finish? | Health and status on the row |
| Why can a cashier not redeem at one terminal? | Terminals in the detail panel, checking the POS id is mapped |
| Is the merchant still paying for this? | Billing state |
| Is this the test or the live setup? | Environment switch |
| Which Taliup location is this Factor4 account? | Merchant and location on the row |
