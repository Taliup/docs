The **Performance Reports** page lets ISO admins generate merchant performance reports for any date range and merchant scope within their ISO. Reports are processed as background jobs and exported as multi-sheet Excel (.xlsx) files ready for download.

<Frame caption="The Performance Reports page showing the report generation form, Report Information panel, and the Generated Reports list.">
  ![Performance Reports page with the Generate New Report form on the left, the Report Information panel on the right, and an empty Generated Reports list below](/images/taliup-hq/performance.png)
</Frame>

<Note>
  This page is only accessible to users with an ISO associated with their account. Users without an ISO assignment receive a 403 error. Reports are scoped to your ISO — you can only generate and view reports for merchants within your accessible ISO hierarchy.
</Note>

## Generate new report

<Frame caption="The Generate New Report form showing Report Type, Merchants, date range inputs, and Quick Date Presets.">
  ![Generate New Report form with Merchant Performance Report type, All Merchants checkbox, From and To date/time fields, and preset buttons for Last 7 Days, Last 30 Days, This Month, and Last Month](/images/taliup-hq/performance-form.png)
</Frame>

| Field | Description |
|---|---|
| **Report Type** | Fixed to **Merchant Performance Report** — the only report type currently available. |
| **Merchants** | Check **All Merchants** (default) to include every merchant in your ISO scope. Uncheck to reveal a searchable multi-select for targeting specific merchants by name or city. |
| **From Date & Time** | Start of the reporting window. Defaults to the current date at 12:00 AM. |
| **To Date & Time** | End of the reporting window. Defaults to the current date at 11:59 PM. Must be on or after the From date. |
| **Quick Date Presets** | One-click shortcuts to fill the date range: **Last 7 Days**, **Last 30 Days**, **This Month**, or **Last Month**. |

Click **Generate Report** to open the confirmation modal before the job is submitted.

## Report contents

<Frame caption="The Report Information panel showing what is included in the generated Excel file.">
  ![Report Information panel listing Report Contents, Export Format, and Process sections](/images/taliup-hq/performance-report-info.png)
</Frame>

Each generated report is a multi-sheet Excel (.xlsx) file containing:

- Portfolio summary with gross sales, refunds, voids, and net totals
- Payment method breakdown — Cash, Visa, MasterCard, Debit, and other card types
- Tips and taxes collected (GST, PST, HST)
- Individual merchant performance metrics
- Transaction counts and average ticket sizes

The file is structured across multiple sheets for easy manipulation and analysis in Excel or Google Sheets.

## Generating a report

<Steps>
  <Step title="Configure the report">
    Select your merchant scope (all or specific merchants) and set the From and To date range. Use a Quick Date Preset to fill the range automatically.
  </Step>
  <Step title="Click Generate Report">
    The form validates your inputs and opens a confirmation modal showing the exact parameters — Merchants scope, From date/time, and To date/time.
  </Step>
  <Step title="Confirm in the modal">
    Review the parameters and click **Start Generation**. The job is submitted to the background queue immediately.

    <Frame caption="The Confirm Report Generation modal summarising the report parameters before submission.">
      ![Confirm Report Generation modal showing Merchants: All Merchants (7920), From: June 2, 2026 at 12:00 AM, To: July 2, 2026 at 11:59 PM, and a Start Generation button](/images/taliup-hq/performance-confirm-modal.png)
    </Frame>
  </Step>
  <Step title="Monitor status in the list">
    The new report appears in the **Generated Reports** list immediately with a **Pending** status. The list updates automatically as the job progresses — no page reload needed.
  </Step>
</Steps>

## Generated reports list

The **Generated Reports** list below the form shows every report generated by your ISO, newest first. Each row shows the report type, merchant scope, date range, current status, generation timestamp, and available actions.

### Report statuses

<Frame caption="Generated Reports list showing a Pending report (queued but not yet started).">
  ![Generated Reports table row showing Merchant Performance report, Scope: 7920 selected merchants, Range: Jun 2 - Jul 2, with a grey Pending badge](/images/taliup-hq/performance-status-pending.png)
</Frame>

<Frame caption="Generated Reports list showing a Processing report (job is actively running).">
  ![Generated Reports table row with a blue spinning Processing badge indicating the Excel file is being generated](/images/taliup-hq/performance-status-processing.png)
</Frame>

<Frame caption="Generated Reports list showing a Completed report with the Download button available.">
  ![Generated Reports table row with a green Completed badge, a Generated On timestamp of July 2, 2026 at 01:57 PM, and a green Download button](/images/taliup-hq/performance-status-completed.png)
</Frame>

| Status | Meaning |
|---|---|
| **Pending** | The job has been accepted and is waiting in the processing queue. |
| **Processing** | The job is actively running — the Excel file is being generated. |
| **Completed** | The file is ready. A **Download** button appears in the Actions column. |

### Actions

| Action | Description |
|---|---|
| **Download** | Downloads the Excel file via a temporary signed URL. The link is valid for approximately 23 hours from the time the report was generated. |
| **Delete** | Permanently removes the report record and its associated Excel file from storage. |

<Warning>
  Deleting a report is permanent. The Excel file is removed from storage and cannot be recovered. Download the file before deleting if you need to retain it.
</Warning>
