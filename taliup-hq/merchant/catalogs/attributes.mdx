**Attributes** are choices staff pick at the register, like a size or a scent. Each value can change the price. You create an attribute once and add it to as many products as you need.

## Before you start

- Your business needs the **Catalogs** feature. Your Taliup HQ account needs **View Catalogs** to see attributes, **Manage Catalogs** to create or edit them, and **Delete Catalogs** to delete them.

## How to get here

In Taliup HQ, open the **Catalog** group in the sidebar and select **Attributes**. Each row shows the attribute's rule (for example **Required · pick one** or **Optional · up to 3**) and how many products use it.

## Create an attribute

<Steps>
  <Step title="Start a new attribute">
    Select **New attribute**.
  </Step>
  <Step title="Name it and add values">
    Enter the **Name** (for example Size). Under **Values**, type each value (for example Large) and its **Price change**; tap the sign to switch between adding (+) and taking off (−). Select **Add value** for more, and drag values to reorder them.
  </Step>
  <Step title="Set the rules">
    Turn on **Required** when staff must pick a value before the item goes into the sale. Leave **Pick only one** on for a single choice, or turn it off and set **Most values allowed**.
  </Step>
  <Step title="Save">
    Select **Add attribute**. Then add it to products from each product's page. See [Products](/taliup-hq/merchant/catalogs/products).
  </Step>
</Steps>

Restaurants also see, per value:

- **Allow quantity (×2, ×3)** — staff can add the value more than once, like extra cheese ×2.
- **Side selection** — the value can go on the left half, right half or the whole item. Shown when the restaurant has the Ecommerce feature and side selection turned on.

## Change an attribute on one product

On a product's page, edit the attribute in its **Attributes** section. There you can set which values are **Starts selected** for that product. Restaurants with raw materials can also choose the **Raw material** each value **Uses**, the **Quantity used** and **Track stock**. Values, prices and rules still change everywhere the attribute is used.

## Export attributes

Select **Export** to download a spreadsheet of your attributes. You can fill it in and use it with the [product import](/taliup-hq/merchant/catalogs/bulk-import).

## Delete an attribute

Open **More actions** on its row and select **Delete**. It comes off every product that uses it.
